# ZROstrm

> **115 / 夸克网盘 → STRM → 直链 302 → Emby / Jellyfin**

一个把网盘变成媒体库的面板：扫描网盘上的文件，生成 `.strm` 指针交给 Emby/Jellyfin 刮削，
播放时由内置的 302 网关把请求转到网盘直链。**不占本地空间，不做二次转存。**

状态：`0.7.10` 内测 · `linux/amd64` + `linux/arm64` · 专有软件（源码不公开）

> 本仓库只放**文档、部署模板和版本说明**，程序源码不在此仓库。

---

## 它能做什么

- **网盘即媒体库**：115 / 夸克的影视目录生成 STRM 树，Emby 直接识别，播放走 302 直链
- **分享链接一键入库**：粘贴 115 / 夸克分享链接，自动解析、预检直链、生成 STRM 并按类型落库
- **离线下载**：磁力 / ED2K / HTTP 链接交给 115 离线，完成后自动入库
- **自动刮削**：TMDB 匹配海报、背景图、简介、NFO，剧集支持按季批量补单集缩略图
- **Emby 库管理**：标准库一键补建、自定义库（115 / 夸克 / Emby 三边一起建）、网盘分类目录自动挂载
- **多用户**：管理员 / 普通用户分离，普通用户只能写入和删除自己的个人目录
- **资源搜索**：内置 TG 频道搜索，直接拿分享链接入库
- **删除联动**：Emby 里删条目 → 面板出现「待清理」→ 一键把云端源一起删掉（115 与夸克都支持）

## 快速开始

### 前置条件

- 一台能跑 Docker 的机器（NAS / 小主机 / VPS 都行）
- 已经装好 Emby 或 Jellyfin
- 115 网盘账号（扫码登录），可选夸克账号

### 1. 建目录

```sh
mkdir -p zrostrm/{config,media/115strm,media/quarkstrm}
cd zrostrm
```

### 2. 写 `docker-compose.yml`

直接复制本仓库的 [`docker-compose.yml`](./docker-compose.yml)：

```sh
curl -O https://raw.githubusercontent.com/rp168/zrostrm-docs/main/docker-compose.yml
```

### 3. 启动

```sh
docker compose up -d
docker compose logs -f --tail=50
```

### 4. 打开面板

浏览器访问 `http://<机器IP>:5280`，首次进入按引导完成：

1. 扫码登录 115（或夸克）
2. 填 Emby 地址与 API Key
3. 设置默认保存路径
4. 建库 / 绑定已有库

---

## 端口

| 端口 | 用途 | 暴露建议 |
| --- | --- | --- |
| `5280` | 面板 WebUI | **不要直接暴露公网**，走内网或反代加认证 |
| `8020` | STRM 302 网关 | 播放器必须能访问；可反代到域名 |

> 302 网关只做「按 pickcode 取直链并跳转」，不代理视频流量。

## 目录与数据

| 容器路径 | 内容 | 备注 |
| --- | --- | --- |
| `/config` | 面板数据库、网盘 Cookie、设置 | **含凭据，务必备份，别进 git** |
| `/media/115strm` | 115 生成的 `.strm` 树 | Emby 挂载读取 |
| `/media/quarkstrm` | 夸克生成的 `.strm` 树 | Emby 挂载读取 |

## 环境变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `TZ` | `Asia/Shanghai` | 时区，影响日志与定时任务 |
| `CONFIG_DIR` | `/config` | 配置与数据库目录 |
| `STRM_ROOT` | `/media/115strm` | 115 STRM 根目录 |
| `QUARK_STRM_ROOT` | `/media/quarkstrm` | 夸克 STRM 根目录 |
| `WEBUI_PORT` | `5280` | 面板端口 |
| `GATEWAY_PORT` | `8020` | 302 网关端口 |

## 常见问题

**镜像拉不到 / 提示 unauthorized**
镜像目前处于**内测阶段，未公开发布**。获取方式见 [Releases](../../releases) 或提交 Issue 申请测试。

**夸克的大文件播放变成了低分辨率**
夸克账号对**单文件直链**有大小限制（实测 50 MB 起拒绝），超过的会自动走网页播放器的转码流
（通常 1440×810）。要原画质需要账号本身具备大文件直链权益，或改用 115。

**在 Emby 里删了条目，磁盘上的 STRM 也一起没了**
Emby 的「删除」默认会连文件一起删。面板的「待清理」正是为此设计：删掉条目后到面板点一键清理，
云端源和索引会一起收尾。

**面板能不能直接放公网**
不建议。5280 只有口令登录，没有双因素。要外网访问请走反向代理 + HTTPS + 额外认证。
8020 可以单独反代，因为它只做跳转。

**升级会不会丢数据**
不会，数据都在 `/config`。升级镜像后重启即可；跨大版本前建议先备份 `config/` 整个目录。
